# OptimalReader

A high-performance Markdown eReader with synchronized TTS and RSVP focus mode.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```
   npm install
   ```
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your API key
3. Run the app:
   ```
   npm run dev
   ```
